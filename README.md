# Amigo_Secreto

Amigo Secreto

Este projeto é uma aplicação simples de sorteio de Amigo Secreto, permitindo adicionar amigos a uma lista e sortear um nome aleatório.

Tecnologias Utilizadas

HTML

CSS

JavaScript

Funcionalidades

Adicionar nomes à lista de amigos

Validar entradas para evitar nomes vazios

Exibir a lista de amigos adicionados

Sortear aleatoriamente um amigo da lista

Exibir o nome sorteado

Como Usar

Digite o nome de um amigo no campo de entrada.

Clique no botão "Adicionar" para inserir o nome na lista.

Após adicionar todos os participantes, clique em "Sortear amigo".

O nome sorteado será exibido na tela.

Estrutura do Projeto

index.html: Estrutura do site.

style.css: Estilos visuais.

app.js: Lógica do sorteio.
